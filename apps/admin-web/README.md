# Admin 구성원 화면

원본 구성원 목록에서 직원이 없는 경우의 화면을 이관했습니다. 실제 직원·외부 구성원·로그인·권한·서버는 연결되지 않았으며 실무에 사용할 수 없습니다.

개발 환경에서 `VINTAD3E_ADMIN_FIXTURE=1`을 설정하면 합성 직원·외부 구성원 목록과 구성원 상세·앱 권한 표를 볼 수 있습니다. 이메일은 예약된 비운영 도메인입니다. 실제 로그인과 권한 확인은 연결되지 않습니다.

합성 구성원에는 어드민·크루·게스트 예시가 각각 포함됩니다. 앱 접근 값은 화면 확인용이며 실제 사용자 권한이나 접근 규칙을 부여하지 않습니다.

합성 직원 상세는 원본과 같이 시작 전·사용 중·기간 만료·일시 정지·회수 상태를 구분합니다. 계층과 앱 접근 표에는 사용 중인 합성 권한만 반영합니다.

같은 설정으로 `/permissions/apps`에서 앱별 합성 접근 구성원과 메뉴 권한 표를 볼 수 있습니다. 메뉴 권한 값은 표시를 위한 임의의 합성 값이며 실제 권한 규칙·판정이나 권한 부여 기능이 아닙니다.

같은 설정의 변경 기록 화면에서는 합성 기록 21건의 검색·필터·상세와 더 불러오기를 볼 수 있습니다. 실제 변경이나 감사 기록은 읽거나 생성하지 않습니다.

같은 설정의 홈은 합성 앱 상태와 방문 기록을 표시합니다. 서비스 상태를 확인하거나 실제 방문 이력을 조회하지 않습니다.

합성 로그인과 자료를 보려면 아래 실행 전에 같은 터미널에서 설정을 켭니다. Windows PowerShell에서는 `$env:VINTAD3E_ADMIN_FIXTURE = '1'`, macOS 또는 Linux에서는 `export VINTAD3E_ADMIN_FIXTURE=1`을 입력합니다. [전체 실행 순서](../../docs/first-run.md)를 함께 볼 수 있습니다.

Node 24와 Corepack을 준비해 저장소 루트에서 `corepack pnpm install --frozen-lockfile --ignore-scripts` 후 `corepack pnpm --filter @vintad3e/admin-web dev`를 실행하고 `http://127.0.0.1:3832/members`를 엽니다.

같은 설정을 사용하면 `/sign-in`에서 로컬 합성 세션을 만들 수 있습니다. 세션은 개발 환경의 루프백 주소에서만 동작하며 실제 인증이나 업무 권한을 제공하지 않습니다.
