# Apparel 인벤토리 화면

원본 인벤토리의 빈 목록, 분류 탭과 필터를 옮겼습니다. 실제 상품, 재고·권한·로그인과 저장 기능은 연결하지 않았습니다. 필터 선택지는 상품이 없는 경우의 원본 상태입니다. 실무에 사용할 수 없습니다.

`/admin/sales`는 원본의 빈 판매 목록과 검색 필터를 표시합니다. 실제 판매 조회, POS 동기화와 교차 검증은 연결하지 않았으며 두 실행 버튼은 원본 실패 알림을 표시합니다.

개발 환경에서 합성 자료를 켜면 판매내역에서 합성 POS·매장 티켓 두 건의 상세와 검색·필터를 확인할 수 있습니다. 실제 판매나 고객 데이터는 포함하지 않습니다.

개발 환경에서 `VINTAD3E_APPAREL_FIXTURE=1`을 설정하면 합성 상품과 옵션을 목록에 표시합니다. 실제 상품이나 재고는 포함하지 않습니다. 상세에서 저장한 합성 수량은 현재 브라우저 탭의 세션 저장소에 남아 새로고침해도 유지되며 탭을 닫으면 사라집니다. 실제 재고를 입력하지 마세요. 실제 로그인과 서버 저장은 연결되지 않습니다.

합성 재고는 원본의 수량 검증과 저장 알림을 따르며, 저장하지 않은 변경이 있을 때 창을 닫거나 위치 탭을 바꾸면 확인합니다. GitHub 호스팅 Chrome 시험은 이 흐름을 합성 데이터로 확인합니다.

Node 24와 Corepack을 준비해 루트에서 `corepack pnpm install --frozen-lockfile --ignore-scripts` 후 `corepack pnpm --filter @vintad3e/apparel-web dev`를 실행하고 `http://127.0.0.1:3826`을 엽니다.

`/admin/audit`는 원본의 빈 변경 이력과 필터를 표시하며 실행자 이름은 합성 명칭을 사용합니다. 실제 감사 기록과 로그인·권한은 연결하지 않았습니다.
