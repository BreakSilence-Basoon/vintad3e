# Creative 프로젝트 화면

원본 프로젝트 목록의 빈 상태를 이관했습니다. 실제 프로젝트·자료·로그인·권한·서버와 연결되지 않았으며 실제 업무에 사용할 수 없습니다.

개발 환경에서 `VINTAD3E_CREATIVE_FIXTURE=1`을 설정하면 합성 프로젝트 목록을 표시합니다. 원본과 같이 목록 항목은 상세 화면으로 연결되지 않습니다. 실제 프로젝트·인증·권한과는 무관합니다.

같은 설정을 사용하면 `/sign-in`에서 로컬 합성 세션을 만들 수 있습니다. 세션은 개발 환경의 루프백 주소에서만 동작하며 실제 인증이나 업무 권한을 제공하지 않습니다.

같은 설정의 `/confirmations/proposal-01`에서는 합성 변경 제안의 불러오기·검토·확인을 볼 수 있습니다. 합성 결과는 로컬 서버 메모리에 세션별로 남아 같은 세션의 새로고침에서 복구되며, 로그아웃하거나 서버를 다시 시작하면 복구할 수 없습니다. 실제 제안·승인·Codex 실행에는 영향을 주지 않습니다. 다른 제안 번호는 제공하지 않습니다.

합성 화면에서는 제안 15분, 검토 5분의 기한과 합성 데이터의 digest를 표시하며 기한이 지나면 확인을 막습니다. 숫자와 기한은 예시이며 실제 서버 권한·만료·오류 복구는 검증하지 않습니다.

Node 24와 Corepack을 준비해 저장소 루트에서 `corepack pnpm install --frozen-lockfile --ignore-scripts` 후 `corepack pnpm --filter @vintad3e/creative-web dev`를 실행하고 `http://127.0.0.1:3831`을 엽니다.

개발용 합성 자료를 켠 상태에서 `VINTAD3E_CREATIVE_FIXTURE_STATE=empty` 또는 `error`를 설정하면 프로젝트 목록의 빈 상태 또는 읽기 오류를 확인할 수 있습니다. 실제 서버와 연결하지 않습니다.
