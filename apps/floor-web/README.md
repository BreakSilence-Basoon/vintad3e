# Floor 영업일 브리핑과 판매내역 화면

원본 영업일 브리핑과 판매내역의 빈 목록과 기간·검색·정렬 필터를 이관했습니다. 실제 판매·금액·로그인·권한·서버는 연결되지 않았으며 실제 업무에 사용할 수 없습니다.

개발 환경에서 `VINTAD3E_FLOOR_FIXTURE=1`을 설정하면 합성 판매를 바탕으로 한 영업일 브리핑·기간별 매출과 판매 카드, 기간·검색·정렬 및 더 불러오기를 볼 수 있습니다. 표시되는 상품·수량·금액은 합성 값이며 실제 판매·결제·인증·권한과 연결되지 않습니다.

여러 품목이 들어간 합성 판매는 품목별로 지정한 금액을 사용해 브리핑을 계산하고 같은 메뉴는 합산합니다. 단가가 서로 다르면 하나의 단가를 추정하지 않습니다. 실제 영수증이나 금액 배분을 추정하지 않습니다.

Node 24와 Corepack을 준비해 저장소 루트에서 `corepack pnpm install --frozen-lockfile --ignore-scripts` 후 `corepack pnpm --filter @vintad3e/floor-web dev`를 실행하고 `http://127.0.0.1:3830` 또는 `http://127.0.0.1:3830/sales`를 엽니다.

개발 환경에서 합성 자료 설정을 켜면 `/inventory`의 재료 현황과 메뉴별 재료를 읽기 전용으로 볼 수 있습니다. 실제 로그인·재고·저장 및 권한과 연결되지 않습니다.

개발 환경에서 `VINTAD3E_FLOOR_FIXTURE=1`을 설정하면 `/sign-in`에서 로컬 합성 세션을 만들 수 있습니다. 세션은 실제 인증이나 업무 권한을 제공하지 않습니다. `/access-denied`는 접근 거부 화면의 합성 재현이며 실제 경로 접근을 제한하지 않습니다.

개발 환경에서 `VINTAD3E_FLOOR_FIXTURE=1`과 `VINTAD3E_FLOOR_FIXTURE_ADMIN=1`을 설정하면 재고 화면에서 합성 재료를 등록할 수 있습니다. 데이터는 현재 브라우저 탭에만 남으며 실제 권한과 저장소에 연결되지 않습니다. 실제 가게 정보를 입력하지 마세요.

합성 관리자 재고 화면에서 실사 수량을 기록·취소할 수 있습니다. 기록은 현재 탭에만 남고, 기존 합성 재료의 최근 사용량은 2026년 11월 5일의 합성 사용 기록으로 계산합니다. 실제 재고 또는 판매에 연결하지 않습니다.

구매 주문과 입고 완료도 합성 자료로 기록하고 취소할 수 있습니다. 주문 중에는 예상 재고가 바뀌지 않고, 마지막 실사 후 입고된 수량만 예상 재고에 더합니다. 이 기록도 현재 브라우저 탭에만 남습니다.

합성 메뉴의 재료 구성도 현재 탭에서 저장할 수 있습니다. 새 구성은 저장 시점부터 유효하므로 이전의 고정 합성 판매에 소급 적용하지 않습니다.
