# ledger-api 단위 시험 점검

기존 `test`에 포함된 시험은 명령 실행과 HTTP 통합 시험으로, 서버 없는 단위 시험은 0개였다. 다음은 이번에 추가한 범위다.

| 모듈 | 정상 | 빈 자료 | 잘못된 입력 |
| --- | --- | --- | --- |
| DB 초기화 | 새 DB와 권한 생성 | 입력 없음 거부 | 상대 경로·필드 오류·기존 DB 거부 |
| 서비스 설정 | 합성 DB와 공개 키로 준비 | 설정 없음 거부 | 포트·쓰기 설정·가게 불일치 거부 |
| HTTP 요청 처리 | 기존 통합 시험 | 기존 통합 시험 | 기존 통합 시험 |
| 권한 변경·복구 명령 | 기존 명령 통합 시험 | 미확인 | 기존 명령 통합 시험 |

실제 서버는 열지 않는다. HTTP와 명령의 단위 시험은 이번 범위에서 별도로 추가하지 않았다.
