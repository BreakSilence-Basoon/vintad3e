# Library 홈 화면

원본 홈의 문서·파일 피드 구성과 게시물이 없는 상태를 이관했습니다. 제목과 내용은 합성 값입니다. 실제 사내 문서·게시물·로그인·권한·검색 서버는 연결되지 않았으며 실제 업무에 사용할 수 없습니다.

공개 문서·파일 주소에서는 개발 환경에서 명시적으로 켠 합성 텍스트만 열 수 있습니다. 실제 자료의 공개 여부, 저장소와 권한은 연결하지 않았습니다.

기존 `/publications` 주소는 원본처럼 홈으로 이동하며 제목 검색어를 전달합니다.

현재 원본과 같이 기존 `/publish`, `/publications/new` 주소는 홈으로 이동합니다.

개발 환경에서 `VINTAD3E_LIBRARY_FIXTURE=1`을 설정하면 합성 문서·파일 목록과 문서 내용을 볼 수 있고 해당 합성 문서 원본을 다운로드할 수 있습니다. 합성 문서 보관 ID는 브라우저 탭의 세션 저장소에만 남아 새로고침해도 유지되며 탭을 닫으면 사라집니다. 댓글도 각 합성 문서별로 브라우저 탭의 세션 저장소에만 남아 새로고침해도 유지되며 탭을 닫으면 사라집니다. 실제 정보는 입력하지 마세요. 실제 문서·로그인·권한·서버 저장과 연결되지 않습니다.

합성 보관함·댓글 저장 내용이 손상됐거나 알 수 없는 항목을 포함하면 기존 내용을 덮어쓰지 않고 새 저장을 거부합니다. 합성 댓글은 문서당 최대 201개까지 보관합니다.

`/bookmarks`는 저장된 문서가 없으면 원본의 빈 보관함을 표시하며, 합성 자료를 켠 경우 저장한 합성 문서만 표시합니다. 저장소에는 허용된 합성 문서 ID만 기록합니다. `/mypage`에서는 합성 직원이 작성한 것으로 설정된 합성 문서와 현재 탭에서 작성한 댓글을 볼 수 있습니다. `/members`에서는 일반 명칭으로 만든 합성 구성원을 이름으로 검색할 수 있습니다.

회의 상세는 개발 환경에서 명시적으로 켠 합성 회의 한 건을 목록에서 선택해 확인할 수 있습니다. 녹화·녹음과 회의 문서의 실제 업로드 및 등록은 연결하지 않았습니다.

합성 로그인과 자료를 보려면 아래 실행 전에 같은 터미널에서 설정을 켭니다. Windows PowerShell에서는 `$env:VINTAD3E_LIBRARY_FIXTURE = '1'`, macOS 또는 Linux에서는 `export VINTAD3E_LIBRARY_FIXTURE=1`을 입력합니다. [전체 실행 순서](../../docs/first-run.md)를 함께 볼 수 있습니다.

Node 24와 Corepack을 준비해 저장소 루트에서 `corepack pnpm install --frozen-lockfile --ignore-scripts` 후 `corepack pnpm --filter @vintad3e/library-web dev`를 실행하고 `http://127.0.0.1:3829`를 엽니다.

원본의 회의 기록·파일 목록과 파일 올리기 진입 화면을 표시합니다. 개발 환경에서 합성 자료를 켜면 회의 제목을 만들어 같은 브라우저 탭에서 목록과 상세로 다시 열 수 있고, 파일 목록에서 합성 파일 상세로 이동합니다. 회의 제목은 탭의 세션 저장소에만 남으므로 실제 정보를 입력하지 마세요. 실제 회의 저장과 파일 업로드는 연결되지 않았습니다.

합성 회의 상세는 브라우저 저장소를 읽은 뒤 존재 여부를 판정하므로 UUID 형식 주소의 서버 HTML 응답 코드만으로 실제 회의 존재를 판단할 수 없습니다.

파일 상세 화면은 개발 환경에서 명시적으로 켠 단일 가상 텍스트 파일만 열고 내려받습니다. 실제 파일 저장소, 로그인과 권한은 연결하지 않았습니다.

이전 `/documents/[slug]` 주소의 이관되지 않은 문서는 표시하지 않습니다. 합성 로그인이 필요한 경우 로그인으로 이동하고, 로그인한 뒤에도 문서를 찾지 못하면 404를 반환합니다.

개발 환경에서 `VINTAD3E_LIBRARY_FIXTURE=1`을 설정하면 `/sign-in`에서 로컬 합성 세션을 만들 수 있습니다. 세션은 실제 인증이나 업무 권한을 제공하지 않습니다.

같은 설정의 `/confirmations/proposal-01`에서 합성 발행 제안을 검토·확인하고 발행한 합성 문서를 열 수 있습니다. 확인 상태는 개발 서버 메모리에 합성 세션별로 남으며, 같은 세션에서 새로고침해도 복구됩니다. 서버가 재시작되거나 세션이 끝난 뒤에는 복구를 보장하지 않습니다. 실제 문서와 업무 서버에는 저장되지 않습니다.

합성 발행 문서는 홈·내 게시물·상단 검색에 표시되며 다운로드·복사·보관함 저장·댓글·목록 제외를 할 수 있습니다. 변경은 현재 탭에만 남으며 실제 문서와 서버에는 적용되지 않습니다.

같은 설정에서 합성 로그인 후 `/objects/new`의 파일 올리기 흐름을 확인할 수 있습니다. 이 기능은 이름이 `가게 안내.txt`이고 내용이 정확히 `업무를 시작하기 전에 필요한 사항을 확인합니다.`인 UTF-8 파일 한 종류만 받습니다. 나머지 파일은 거부하며 실제 가게 파일을 저장하는 기능이 아닙니다. 합성 업로드는 로컬 서버 메모리에 세션별로 남아 같은 세션에서만 열고 내려받을 수 있고, 서버 재시작이나 로그아웃 뒤에는 사라집니다.

개발용 합성 로그인 후 내부 문서 읽기 경로 두 곳에서 합성 문서와 목차를 볼 수 있습니다. 실제 외부 문서나 직원 자료는 연결하지 않습니다.

[합성 이관 확인 안내](../../docs/library-synthetic-confirmations.md)에서 정해진 단건·묶음·Notion 예시를 확인할 수 있습니다.
