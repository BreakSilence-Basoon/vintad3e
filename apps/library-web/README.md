# Library 홈 화면

원본 홈의 제목 검색과 게시물이 없는 상태를 이관했습니다. 실제 사내 문서·게시물·로그인·권한·검색 서버는 연결되지 않았으며 실제 업무에 사용할 수 없습니다.

기존 `/publications` 주소는 원본처럼 홈으로 이동하며 제목 검색어를 전달합니다.

현재 원본과 같이 기존 `/publish`, `/publications/new` 주소는 홈으로 이동합니다.

개발 환경에서 `VINTAD3E_LIBRARY_FIXTURE=1`을 설정하면 합성 문서 목록·제목 검색·문서 내용을 볼 수 있고 해당 합성 문서 원본을 다운로드할 수 있습니다. 합성 문서 보관 ID는 브라우저 탭의 세션 저장소에만 남아 새로고침해도 유지되며 탭을 닫으면 사라집니다. 댓글도 각 합성 문서별로 브라우저 탭의 세션 저장소에만 남아 새로고침해도 유지되며 탭을 닫으면 사라집니다. 실제 정보는 입력하지 마세요. 실제 문서·로그인·권한·서버 저장과 연결되지 않습니다.

`/bookmarks`는 저장된 문서가 없으면 원본의 빈 보관함을 표시하며, 합성 자료를 켠 경우 저장한 합성 문서만 표시합니다. 저장소에는 허용된 합성 문서 ID만 기록합니다. `/mypage`에서는 합성 직원이 작성한 것으로 설정된 합성 문서와 현재 탭에서 작성한 댓글을 볼 수 있습니다. `/members`에서는 일반 명칭으로 만든 합성 구성원을 이름으로 검색할 수 있습니다.

회의 상세는 개발 환경에서 명시적으로 켠 합성 회의 한 건을 목록에서 선택해 확인할 수 있습니다. 녹화·녹음과 회의 문서의 실제 업로드 및 등록은 연결하지 않았습니다.

Node 24와 Corepack을 준비해 저장소 루트에서 `corepack pnpm install --frozen-lockfile --ignore-scripts` 후 `corepack pnpm --filter @vintad3e/library-web dev`를 실행하고 `http://127.0.0.1:3829`를 엽니다.

원본의 회의 기록·파일 목록과 파일 올리기 진입 화면을 빈 상태로 표시합니다. 회의 생성과 파일 업로드는 연결되지 않아 요청 시 원본 오류를 표시하며 실제 회의나 파일을 저장하지 않습니다.

파일 상세 화면은 개발 환경에서 명시적으로 켠 단일 가상 텍스트 파일만 열고 내려받습니다. 실제 파일 저장소, 로그인과 권한은 연결하지 않았습니다.
