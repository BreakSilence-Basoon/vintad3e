# Partners 일정 화면

원본 협업·대관 캘린더와 일정이 없는 상태를 이관했습니다. 실제 협업 일정·파트너·금액·로그인·권한·서버와 연결되지 않았으며 실제 업무에 사용할 수 없습니다.

개발 환경에서 `VINTAD3E_PARTNERS_FIXTURE=1`을 설정하면 합성 대관 일정과 수납 완료·미수납 목록 및 상세를 표시합니다. 금액과 거래처는 합성 값이며 실제 파트너, 정산, 로그인 및 권한 확인과 연결되지 않습니다.

같은 개발 설정에서 `/dj`의 원본 전달문 작성과 지급 목록을 확인할 수 있습니다. 입력은 화면 메모리에만 머물고 화면을 떠나면 지워지며, 복사 버튼은 사용자가 입력한 전체 번호를 클립보드로 복사합니다. 실제 개인정보는 입력하지 마세요. 로그인·권한·실제 정산 및 DJ 가이드는 연결되지 않았습니다. 개발 설정이 없거나 운영 환경에서는 이 주소를 제공하지 않습니다.

같은 설정의 달력에서 DJ 일정을 선택하면 합성 지급 내역 두 건과 지급 상태·정산 조건을 볼 수 있습니다. 이 자료는 실제 DJ·계약·지급과 무관합니다.

Node 24와 Corepack을 준비해 저장소 루트에서 `corepack pnpm install --frozen-lockfile --ignore-scripts` 후 `corepack pnpm --filter @vintad3e/partners-web dev`를 실행하고 `http://127.0.0.1:3828`을 엽니다.

개발 설정의 `/proj-bedroom`에서는 합성 협업처 두 곳의 목록과 각 협업처의 조건·지급 내역을 표시합니다. 이름·비율·금액·문서 주소는 모두 합성 값이며 실제 협업처나 계약과 무관합니다. 설정이 없거나 운영 환경에서는 제공하지 않습니다.

원본처럼 협업 영역과 협업처 주소를 동적 경로로 처리하며 알려지지 않은 영역·협업처는 404입니다. 기존 DJ·대관·협업처의 합성 화면과 표시 내용은 동일합니다.
