# 포털 아이콘 바꾸기

이 폴더의 SVG는 빈타제에서 직접 만든 단순 도형과 이니셜입니다. 앱 아이콘은 `apparel.svg`처럼 앱 이름으로, 외부 서비스 자리는 `service-instagram.svg`처럼 `service-`로 시작하는 이름으로 저장합니다. 글자 이니셜은 해당 서비스의 공식 로고가 아닙니다.

내 가게에서 쓸 아이콘을 준비한 뒤 해당 파일을 같은 이름의 SVG로 바꾸고 포털을 새로고침하세요. 사용할 권리가 있는 이미지만 넣으세요. 원본 SVG는 이 저장소의 [라이선스](../../../../../LICENSE)를 따릅니다.
