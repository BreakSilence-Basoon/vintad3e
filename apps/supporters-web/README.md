# Supporters 쿠폰 화면

원본에서 쿠폰을 발급받은 서포터즈가 없는 경우의 화면을 이관했습니다. 실제 직원 정보·쿠폰·로그인·권한·정산과 연결되지 않았습니다. 약관과 개인정보처리방침 링크의 본문도 없습니다. 실무에 사용할 수 없습니다.

Instagram과 TikTok은 원본에서 관리자에게 연결된 서포터즈가 없을 때의 화면을 표시합니다. 실제 SNS 연결·로그인·권한·성과 데이터는 연결하지 않았습니다.

개발 환경에서 합성 자료를 켜면 Instagram과 TikTok에서 합성 서포터즈 두 명의 게시물을 각각 선택·정렬할 수 있습니다. 합성 게시물 링크는 비운영 도메인이며 실제 계정이나 게시물은 읽지 않습니다. 관리자의 게시물 등록 표시는 읽기 전용입니다.

같은 설정의 `/settlements`에서는 합성 구성원과 합성 금액·지급 상태를 확인하고 체크할 수 있습니다. 체크는 현재 브라우저 탭의 세션 저장소에만 남고 탭을 닫으면 사라집니다. 실제 정산과 지급·로그인·권한에는 연결하지 않습니다.

두 합성 구성원의 2026년 10월 금액과 지급 체크는 각각 별도입니다. 금액은 예시로 정해 놓은 값이며 합성 게시물에서 계산하지 않습니다.

개발 환경에서 `VINTAD3E_SUPPORTERS_FIXTURE=1`을 설정하면 합성 서포터즈를 선택할 수 있으며, 사용 정보가 있는 합성 구성원의 쿠폰 코드와 사용 횟수를 볼 수 있습니다. 다른 구성원을 선택하면 원본처럼 사용 정보가 표시되지 않습니다. 복사되는 링크는 예약된 비운영 도메인 `example.invalid`를 사용합니다. 실제 쿠폰 발급·인증·권한 확인과는 연결되지 않습니다.

같은 설정의 홈(`/`)에서는 합성 구성원 선택과 성과·쿠폰 사이트 통계 화면을 볼 수 있습니다. 수치와 통계는 화면 확인용이며 실제 SNS, 판매 또는 정산 정보를 읽거나 계산하지 않습니다. 설정하지 않으면 홈을 표시하지 않습니다.

Node 24와 Corepack을 준비해 저장소 루트에서 `corepack pnpm install --frozen-lockfile --ignore-scripts` 후 `corepack pnpm --filter @vintad3e/supporters-web dev`를 실행하고 `http://127.0.0.1:3827/coupon`을 엽니다.

개발 환경에서 `VINTAD3E_SUPPORTERS_FIXTURE=1`과 `VINTAD3E_SUPPORTERS_FIXTURE_SELF=1`을 함께 설정하면 본인 화면의 합성 게시물 등록·해제와 합성 연결 상태를 조작할 수 있습니다. 상태는 현재 브라우저 탭의 세션 저장소에만 남고 실제 SNS 계정·로그인·권한·공식 API에는 연결되지 않습니다. 수동 갱신은 실제 SNS에 요청하지 않습니다.
