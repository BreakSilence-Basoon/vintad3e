# timetable-api 단위 시험 점검

기존 시험은 HTTP·명령 통합 시험으로 서버 없는 단위 시험은 0개였다. 합성 인증과 DB 응답을 사용하며 서버를 열지 않는다.

| 모듈 | 정상 | 빈 자료 | 잘못된 입력 |
| --- | --- | --- | --- |
| 직원 목록 요청 | 합성 직원 | 빈 목록 | 매개변수·권한·저장 자료 |
| 일정 목록 요청 | 합성 일정 | 빈 목록 | 날짜·커서·권한·저장 자료 |
| 관리자 상세·변경 요청 | 상세 조회 | 없는 상세·빈 본문 | 경로·권한·형식 오류 |
| 루프백 서버 설정 | 서버 객체 생성 | 처리기 없음 | 잘못된 옵션 |
| DB 초기화 | 기존 통합 시험 | 입력 없음 거부 | 상대 경로 거부 |
| 서비스 준비·복구·DB 관리 명령 | 기존 통합 시험 | 미확인 | 기존 통합 시험 |

합성 응답 단위 시험은 실제 DB 쿼리와 네트워크 동작을 보증하지 않는다. 쓰기 성공과 서버 요청 처리는 기존 통합 시험 범위다.
