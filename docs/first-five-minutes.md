# 설치 후 첫 5분

설치가 끝나고 포털이 실행된 뒤, 어떤 화면이 있는지 살펴보는 순서입니다. 설치 전이라면 먼저 [처음 실행하기](first-run.md)를 따라 주세요. 이 화면의 상품과 수량은 예시입니다. 실제 직원·고객·매출 정보는 입력하지 마세요.

1. 실행 중인 터미널을 열어 둔 채 브라우저에서 [포털](http://127.0.0.1:3825)을 엽니다. **회사 계정으로 로그인**을 누르면 비밀번호 입력 없이 포털로 이동합니다. 이 버튼은 내 컴퓨터에서만 쓰는 가상 로그인입니다.
2. 포털에서 업무 앱의 이름을 살펴보고 화살표나 아래쪽 점으로 다른 목록도 넘겨 보세요. 앱은 각각 따로 실행해야 열립니다. 아직 실행하지 않은 앱을 누르면 연결할 수 없다는 브라우저 안내가 나올 수 있습니다.
3. 예시로 재고 화면을 열려면 포털을 켜 둔 채 터미널을 하나 더 열고, 내려받은 `vintad3e` 폴더로 이동합니다. Windows PowerShell에서 아래 두 줄을 입력하세요.

   ```powershell
   $env:VINTAD3E_APPAREL_FIXTURE = '1'
   corepack pnpm --filter @vintad3e/apparel-web dev
   ```

   macOS 터미널에서는 아래 한 줄을 입력합니다.

   ```sh
   VINTAD3E_APPAREL_FIXTURE=1 corepack pnpm --filter @vintad3e/apparel-web dev
   ```

4. 앱이 시작되면 포털의 **Apparel**을 누르거나 [Apparel](http://127.0.0.1:3826)을 직접 엽니다. 로그인 화면이 나오면 같은 버튼을 누릅니다. [상품 관리](http://127.0.0.1:3826/admin/products)에서 예시 상품을 검색하고 옵션별 수량을 살펴볼 수 있습니다.
5. 다른 화면은 [앱별 실행 주소](first-run.md#다른-앱-열기)와 각 앱의 안내를 확인하세요. 포털 로그인은 다른 앱의 로그인을 대신하지 않습니다. 끝낼 때는 실행한 각 터미널에서 Ctrl+C를 누릅니다.

일부 예시 변경은 현재 브라우저 탭이나 실행 중인 서버에만 남습니다. 실제 가게 데이터를 안전하게 저장·공유하는 기능은 아직 연결되지 않았습니다. 자세한 범위는 [지금 할 수 있는 일](what-is-available.md)을 확인하세요.
