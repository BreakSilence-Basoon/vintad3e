# 우리 가게 재고를 연결하는 세 가지 방법

빈타제에 가게 재고를 넣는 방법을 고르기 위해 옷 재고 화면에 세 가지 시제품을 만들었습니다. **셋 다 아직 실제 가게에서 쓸 제품이 아닙니다.** 직원·고객 정보나 실제 매출을 넣지 말고 예시 파일로만 살펴보세요. 최종 선택은 basoon(바순)이 합니다.

| 궁금한 점 | [파일 가져오기 #225](https://github.com/BreakSilence-Basoon/vintad3e/pull/225) | [내 컴퓨터에 저장 #228](https://github.com/BreakSilence-Basoon/vintad3e/pull/228) | [별도 서버에 연결 #229](https://github.com/BreakSilence-Basoon/vintad3e/pull/229) |
| --- | --- | --- | --- |
| 어떻게 쓰나요? | 재고가 적힌 파일을 골라 화면에서 확인합니다. | 파일을 확인한 뒤 이 컴퓨터에 저장합니다. | 별도로 실행한 프로그램에 파일을 보내 확인합니다. |
| 어떤 때 어울리나요? | 혼자 기존 재고를 잠깐 살펴볼 때 | 한 컴퓨터에서 재고를 계속 보관할 때 | 여러 기기에서 같은 재고를 함께 써야 할 때를 위한 출발점 |
| 지금 시제품은 어디에 남나요? | 화면을 나가면 사라집니다. | 컴퓨터의 `.data` 폴더에 남습니다. | 프로그램을 끄면 사라집니다. |
| 여러 사람이 함께 쓸 수 있나요? | 한 사람의 화면에서만 봅니다. | 직원별 권한과 안전한 동시 사용은 아직 없습니다. | 지금은 같은 컴퓨터의 여러 브라우저에서만 공유합니다. 여러 기기의 안전한 사용은 아직 없습니다. |
| 백업은요? | 원본 파일을 따로 보관해야 합니다. | 자동 백업과 복구 기능이 아직 없습니다. | 백업이 아직 없습니다. 실제 사용 전 저장·백업·복구 방법이 필요합니다. |
| 조심할 점은요? | 파일을 열 수 있는 사람이 내용을 볼 수 있습니다. | 컴퓨터를 잃거나 고장 나면 저장한 내용도 잃을 수 있습니다. 파일 암호화가 없습니다. | 실제 로그인과 통신 보호가 없어 인터넷에 공개하면 안 됩니다. 운영과 보안 관리가 필요합니다. |
| 만들기 어려운 정도 | 세 가지 중 가장 간단합니다. | 저장과 복구를 만들어야 해 더 어렵습니다. | 계정·권한·백업과 운영이 필요해 가장 어렵습니다. |

예를 들어 **혼자 재고 파일을 살펴보는 가게**라면 첫 번째부터, **한 컴퓨터에 계속 저장해야 하는 가게**라면 두 번째를, **여러 직원이 각자 다른 기기에서 함께 써야 하는 가게**라면 세 번째를 검토할 수 있습니다. 지금은 어떤 방식도 실제 자료를 안전하게 지키는 기능이 완성되지 않았으므로, 선택한 뒤 필요한 기능을 만들어야 합니다.

나머지 여덟 앱까지 연결할 때의 대략적인 작업량은 파일 방식이 앱당 3~7 개발일, 내 컴퓨터 저장이 앱당 2~4 개발주, 서버 연결이 앱당 4~8 개발주 이상입니다. 한 사람이 개발한다는 거친 예상이며, 공통 인증·보안·백업, 실제 운영과 법률 검토는 포함하지 않습니다. 필요한 앱만 선택하면 총량도 달라집니다.

세 변경안은 서로 다른 선택지이며 함께 합치는 것을 전제로 하지 않습니다. 가게마다 필요한 개인정보처리방침과 이용약관은 각 가게가 직접 준비해야 합니다. 자세한 판단 기준은 [가게 데이터 연결 방식](store-data-options.md)을 보세요.
