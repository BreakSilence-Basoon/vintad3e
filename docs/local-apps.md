# 다른 앱 화면 실행하기

처음이라면 [포털과 다른 앱 처음 실행하기](first-run.md)를 순서대로 따라 하세요. 저장소 내려받기, 설치, 각 앱의 주소와 합성 자료를 여는 방법이 한곳에 정리돼 있습니다. 실행 중인 앱을 닫으려면 해당 터미널에서 Ctrl+C를 누릅니다.

이 화면들은 실제 직원·고객·판매 자료를 안전하게 보관하는 업무용 앱이 아닙니다. 각 앱에 표시되는 내용과 제한은 [공개판 안내](what-is-available.md)를 확인하세요.

개발 서버가 `next-env.d.ts`의 자동 생성 경로를 바꿀 수 있습니다. 코드를 수정하기 전에 `git status`와 `git diff`로 변경을 확인하세요. 자신의 변경을 확인하지 않고 파일을 지우거나 덮어쓰지 마세요.

## PC·모바일 첫 화면 검사

Chrome을 설치한 뒤 저장소 루트에서 `corepack pnpm test:browser-smoke`를 실행하면 포털과 앱의 합성 첫 화면을 1440px과 390px 폭에서 확인합니다. 앱별 합성 자료 설정을 켜고 필요한 화면에서는 합성 로그인을 실행합니다. 빈 화면, 브라우저 오류와 일부 잘린 글자를 검사합니다. 실제 계정 인증·권한과 업무 데이터 검사가 아니며 자동 검사가 모든 화면 배치 문제를 찾지는 못합니다. 앱 이름을 뒤에 지정하면 해당 앱만 검사합니다(예: `corepack pnpm test:browser-smoke portal`). 개발 서버는 로컬 임시 포트에서 앱을 하나씩 실행합니다.

앱마다 어떤 첫 화면과 주요 흐름을 검사하는지는 [브라우저 검사 범위](browser-coverage.md)를 확인하세요. 공통 검사는 Creative의 로그인 화면까지 확인하며, 로그인 뒤 홈과 주요 흐름은 Creative의 별도 검사에서 확인합니다.
