# 포털 단위 시험 점검

서버를 열지 않고 합성 자료와 메모리 안의 요청으로 확인한다. 화면 시험은 실제 브라우저 대신 화면을 HTML로 만드는 결과를 확인하며, 로그인과 외부 화면 연결은 대체 객체를 사용한다. `해당 없음`은 그 모듈에 해당 입력이 없다는 뜻이다.

| 모듈 | 정상 | 빈 자료 | 잘못된 입력 | 범위와 남은 점 |
| --- | --- | --- | --- | --- |
| 앱 연결 목록 | 확인 | 확인 | 확인 | 권한과 목록 복사 확인 |
| 로그인 안내 분류 | 확인 | 확인 | 확인 | 알 수 없는 분류와 자료형 포함 |
| 합성 세션 | 확인 | 확인 | 확인 | 주소, 출처, 만료와 로그아웃 포함 |
| 확인 단계 | 확인 | 확인 | 확인 | 순서와 만료 포함 |
| 확인 자료 저장 | 확인 | 확인 | 확인 | 잘못된 본문과 권한 없는 요청 포함 |
| 합성 로그인 요청 | 확인 | 확인 | 일부 | 길이 헤더가 없는 큰 본문 제한은 아래 문제 참고 |
| 합성 로그아웃 요청 | 확인 | 확인 | 확인 | 세션과 출처 확인 |
| 합성 확인 요청 | 확인 | 확인 | 확인 | 요청 본문과 세션 확인 |
| 첫 화면 | 확인 | 확인 | 확인 | 목록·빈 목록·오류 화면과 잘못된 호스트 |
| 로그인 화면 | 확인 | 확인 | 확인 | 이동 주소와 로그인 상태 |
| 세션 복귀 화면 | 확인 | 해당 없음 | 확인 | 안전하지 않은 이동 주소와 로그아웃 상태 |
| 확인 화면 경로 | 확인 | 확인 | 확인 | 없는 번호와 로그인하지 않은 경우 |
| 앱 목록 넘김 | 확인 | 확인 | 해당 없음 | 최초 화면만 확인; 넘김 조작은 브라우저 시험 범위 |
| 상단 메뉴 | 확인 | 해당 없음 | 해당 없음 | 로그인·로그아웃 링크 표시 |
| 확인 화면 구성 요소 | 확인 | 확인 | 해당 없음 | 최초 상태만 확인; 이후 누르기와 오류는 브라우저 시험 범위 |
| 로그인 알림 구성 요소 | 확인 | 확인 | 해당 없음 | 표시 내용만 확인; 시간에 따른 닫힘은 브라우저 시험 범위 |
| 소개·오류 화면과 공통 배치 | 확인 | 해당 없음 | 해당 없음 | 정적 표시 확인 |

## 확인된 문제

개발용 로컬 합성 로그인에서 `Content-Length` 헤더가 없는 5,005바이트 본문을 요청 처리 함수에 직접 전달했을 때, 4KB 제한 대신 로그인 응답이 반환됐다. 실제 HTTP 환경에서도 같은 요청이 전달되는지는 확인하지 않았다. 동작 코드는 이 점검에서 변경하지 않았다.
