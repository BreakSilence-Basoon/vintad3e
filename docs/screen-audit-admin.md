# Admin 화면별 대조

원본과 공개판의 화면 코드를 비교했습니다. 공개판은 합성 계정과 자료를 사용하므로 실제 직원 권한과 회사 서버에 따른 분기는 검증하지 않았습니다. 브라우저 검사는 [구성원 검사](../apps/admin-web/src/members-fixture-browser.test.mjs)와 [키보드 검사](../apps/admin-web/src/interaction-keyboard-browser.test.mjs)를 참고하세요.

| 화면 | 원본에서 확인한 화면과 동작 | 공개판의 상태와 남은 차이 |
| --- | --- | --- |
| `/` | 앱별 상태·마지막 방문 정보와 앱 이동. | 합성 상태·방문 정보와 공개 화면이 있는 앱의 이동 제공. 실제 상태와 방문 기록은 미연결. |
| `/members` | 직원·협업자 전환, 상세·변경 이력 이동, 다음 목록·처음부터 보기. 빈 목록, 잘못된 이어보기 주소와 조회 오류 안내. | 합성 목록·전환·상세·이동, 빈 목록·잘못된 주소·합성 조회 오류 안내 제공 ([#319](https://github.com/BreakSilence-Basoon/vintad3e/pull/319)). 실제 접근 범위와 서버는 미연결. |
| `/members/[staffId]` | 구성원 정보·앱 권한과 권한 화면 이동. 접근 거부, 없는 구성원, 권한 없음과 조회 오류 안내. | 합성 구성원과 앱 권한·이동 제공. 실제 구성원별 접근 범위와 회사 권한 서비스 오류는 미연결. |
| `/audit` | 키워드·기간·실행자·정렬 입력, 적용·초기화·더 불러오기와 이력 조회. | 같은 입력과 합성 이력 조회 제공. PC·모바일 폭에서 빈 검색 결과, 직접 기간의 빈 결과·역순·종료일만 입력, 정렬·초기화·더 불러오기를 검사. 실제 변경 이력과 조회 권한·서버 오류는 미연결. |
| `/permissions` | 계층 선택과 앱별 접근표 조회. | 합성 계층 선택과 접근표 제공. 실제 권한과 서버 조회·접근 거부 분기는 미연결. |
| `/permissions/apps` | 앱 선택, 메뉴별 권한과 접근하는 사람 조회. | 합성 앱 선택·메뉴 권한·구성원 표 제공. 실제 권한과 서버 조회·접근 거부 분기는 미연결. |
| `/sign-in` | 로그인, 로그인 화면 보기·복귀와 인증 오류 안내. | 합성 로그인과 로그인 화면 보기·복귀 제공. 실제 인증 오류와 실제 권한 거부는 미연결. |

실제 서버의 모든 빈 응답과 오류, 계정별 권한 범위는 공개판의 합성 검사만으로 원본과 같다고 판단할 수 없습니다.
