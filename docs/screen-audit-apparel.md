원본 화면과 공개판의 합성 흐름을 비교했습니다. 실제 상품·재고·판매·직원 정보와 권한 서버는 연결하지 않았습니다. 검사 근거는 [재고](../apps/apparel-web/src/inventory-stock-browser.test.mjs), [부족 재고](../apps/apparel-web/src/shortage-fixture-browser.test.mjs), [매출 통계](../apps/apparel-web/src/sales-overview-browser.test.mjs), [키보드 동작](../apps/apparel-web/src/interaction-keyboard-browser.test.mjs)입니다.
