# Floor 화면별 대조

허용된 원본 화면과 공개판 코드를 비교했습니다. 공개판은 합성 계정·자료를 사용하므로 실제 직원 권한과 회사 서버는 검증하지 않았습니다. 검사 근거는 [판매 검사](../apps/floor-web/src/sales-fixture-browser.test.mjs)와 [키보드 검사](../apps/floor-web/src/sales-keyboard-browser.test.mjs)입니다.

| 화면 | 원본에서 확인한 구성·동작 | 공개판의 상태와 남은 차이 |
| --- | --- | --- |
| `/` | 영업일 이동·날짜 선택, 일별 요약·추이와 빈 영업일·조회 오류 표시. | 합성 날짜 이동·요약·빈 상태와 오류 화면 제공. 전날·다음날 이동, 최신일 제한, 날짜 직접 입력, 빈 영업일과 유효하지 않은 날짜를 PC·모바일에서 검사. 실제 판매 서버와 계정 권한은 미연결. |
| `/sales` | 기간·검색·정렬 조건과 판매 목록·더 불러오기, 빈 결과 안내. | 합성 판매 조회·조건·더 불러오기·빈 결과 제공. 기간 5종·정렬 2종·검색 유무의 20개 조합을 단위 검사하고, 30일·오래된 순 조건과 더 불러오기, 직접 기간 입력을 PC·모바일에서 검사. 실제 판매와 외부 갱신 내역은 미연결. |
| `/inventory` | 재료 등록·구성, 구매·입고·실사 입력과 기록 취소, 조회 실패 안내. | 합성 재료 등록·중복 거부·구성 변경, 구매·입고·실사와 취소, 조회 실패를 PC·모바일 검사에서 확인. 손상된 합성 기록의 수정 제한과 추가 재료 100개 경계를 검사. 실제 재고 서버·직원별 쓰기 권한은 미연결. |
| `/access-denied` | 접근할 수 없는 이유를 안내하고 다른 계정 로그인으로 이동. | 합성 안내와 로그아웃·로그인 이동을 PC·모바일에서 검사. 실제 접근 거부 판정과 계정 전환은 미연결. |
| `/sign-in` | 로그인과 로그인 화면 보기·복귀, 인증 실패 안내. | 합성 로그인·화면 보기·복귀와 원본 오류 안내를 제공. 중복된 화면 보기 값, 복귀 주소의 검색 조건, 알려진 오류·알 수 없는 오류 및 주소 정리를 PC·모바일에서 검사. 실제 인증 제공자는 미연결. |
| `/auth/session-resume` | 안전한 주소를 유지하고 세션 갱신 뒤 재인증으로 이동. | 합성 세션에 따라 로그인 또는 돌아갈 주소로 이동. 실제 갱신은 미연결. |
| `/confirmations/[proposalId]` | 서버 제안과 권한 확인, 검토·승인, 만료·오류·재인증 안내. | 합성 제안의 불러오기·검토·확인, 권한 없음·변경·로그인 필요·세션 회수·잘못된 요청·서버 오류와 복구를 PC·모바일에서 검사. 합성 재로그인, 세션 분리·검토 기한·알 수 없는 제안을 검사. 실제 서버 제안·권한·재인증은 미연결. |

위 표는 합성 검사에서 확인한 범위와 실제 연결이 필요한 부분을 구분하며, 미대조 분기까지 일치한다고 뜻하지 않습니다.

원본과 공개판의 날짜 파서는 날짜 형식은 확인하지만 존재하지 않는 날짜는 자동 보정합니다. 브라우저 시험은 형식이 잘못된 입력을 대상으로 하며, 달력에 없는 날짜를 거부한다고 뜻하지 않습니다.
