# 화면·기능 대조 후속 목록

이 기록은 원본 코드와 vintad3e의 합성 화면을 대조한 목록입니다. 실제 계정·권한·가게 데이터·외부 서버를 연결하거나 실제 사용자 경로를 검증한 결과는 아닙니다. 이 목록은 구현 결정이 아닙니다.

## 로그인 안내를 맞춘 앱의 다른 화면

| 앱 | 공개판에서 제공하는 구조와 동작 | 원본과 남은 차이 |
| --- | --- | --- |
| Partners | 협업 일정·영역·합성 협업처, 읽기 전용 합성 게스트, 정산 기간 조회와 가이드 탐색 | 실제 협업처·판매·정산과 계정 권한은 미연결. 원본의 회사별 별도 쇼룸 정산 경로는 공개판에 그대로 없고 합성 협업처 정산 화면이 따로 있음. 개인정보처리방침은 각 가게가 직접 준비. 사진·영상·실제 협업 조건은 제외했고 가이드의 나머지 세부는 추가 대조 필요. [상세 기록](screen-audit-partners.md) |
| Supporters | 합성 기간 조회·쿠폰 복사·SNS 성과·정산 상태, 합성 확인 화면 | 실제 계정·쿠폰 주문·SNS 연결·권한은 미연결. 원본의 개인정보처리방침과 약관 화면은 공개판에 없으며 각 가게가 직접 준비. 원본의 실제 정산 공식·금액·억제 로직은 제외. [상세 기록](screen-audit-supporters.md) |
| Portal | 합성 업무 앱 목록·화면 전환·로그아웃·소개·확인 화면 | 실제 앱 접근 권한·인증·제안과 서버 오류는 미연결 또는 미대조. 회사 전용 링크·이미지·소개 원문은 제외. [상세 기록](screen-audit-portal.md) |
| Creative | 합성 프로젝트 목록·빈 상태·조회 오류와 정해진 합성 제안 확인 | 실제 프로젝트 서버·직원 접근 권한·업무 변경 실행은 미연결. 실제 권한 거부·재인증 상태는 미대조. [상세 기록](screen-migration-audit.md#creative) |
| Admin | 합성 구성원 목록·상세, 앱별 권한표와 감사 이력 검색·정렬 | 실제 구성원·권한·변경 이력과 서버의 접근 거부·조회 오류는 미연결 또는 미대조. [상세 기록](screen-audit-admin.md) |

원본과 공개판의 페이지 파일 수는 Portal 5·5, Creative 3·3, Admin 7·7, Supporters 13·11, Partners 15·13입니다. 경로의 이름과 역할이 다를 수 있으므로 이 수는 기능 완성률이 아닙니다. Partners의 회사별 고정 주소는 공개판에서 합성 협업처 주소로 대체한 경우가 있습니다.

## Library에서 아직 제공하지 않는 기능

| 기능 | 원본 | vintad3e의 현재 범위와 차이 |
| --- | --- | --- |
| 파일 올리기 | 파일 선택 후 업로드 제안과 권한·승인을 확인하고, 승인된 전송 세션으로 파일을 전송·완료함. 중단된 전송의 복귀와 진행 상태, 나가기 경고를 다룸. | 지정된 합성 파일의 이름·내용이 일치하는 경우만 합성 확인과 올리기 가능. 실제 파일·저장소·권한과 재개 가능한 실제 전송은 미연결. 합성 업로드 API는 합성 세션과 고정 파일을 검사하지만 화면에서 만든 승인 제안과 업로드 요청을 서버에서 묶어 검사하지 않으므로 실제 승인 보호로 사용할 수 없음. [화면](../apps/library-web/src/records-entry-forms.tsx) · [합성 업로드](../apps/library-web/src/fixture-upload.mjs) |
| 내부 문서 이관 | 원본 문서와 첨부를 검증한 단건·묶음 제안, 첨부 예약·연결, 삭제·복구와 안전한 첨부 정리 경로를 다룸. | 고정된 합성 단건·묶음과 지정 첨부만 시험 경로에서 준비해 확인 가능. 격리 합성 파일만 정리하며 공유할 수 있는 파일은 정리하지 않음. 실제 내부 문서·첨부·감사 기록·권한 및 서버 연결은 미제공. [합성 확인](../apps/library-web/src/fixture-ir-confirmation.mjs) · [상세 범위](library-synthetic-confirmations.md) |
| 만료된 Notion 제안 다시 받기 | 미실행 상태의 만료 또는 취소된 삭제·복구 제안에 대해 원래 제안과 문서 개정·이관 근거를 확인하고, 같은 내용의 재발급 결과를 복구하거나 새로 준비하는 별도 서버 경로가 있음. | 합성 제안은 기한이 지나면 제거되며 기존 제안을 다시 받는 경로가 없음. 합성 예시는 다시 만들어야 함. 실제 Notion·원본 자료·인증 및 권한 서버는 미연결. [합성 확인](../apps/library-web/src/fixture-ir-confirmation.mjs) |

원본 근거는 비공개 원본 저장소의 `apps/library/src/components/object-upload-form.tsx`, `apps/library/src/app/api/ir/prepare/route.ts`, `apps/library/src/app/api/notion-migration/lifecycle/renew/route.ts`에서 읽기 전용으로 확인했습니다. 이 목록에 없는 입력 조합과 실제 서버 오류는 미확인입니다.
