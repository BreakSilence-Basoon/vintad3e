# Library 화면별 대조

원본 화면과 공개판의 합성 흐름을 비교했습니다. 실제 문서·회의·직원 정보와 권한 서버는 연결하지 않았습니다. 검사 근거는 [자료](../apps/library-web/src/library-fixture-browser.test.mjs), [기록](../apps/library-web/src/library-records-browser.test.mjs), [키보드 동작](../apps/library-web/src/interaction-keyboard-browser.test.mjs), [내부 문서](../apps/library-web/src/internal-document-browser.test.mjs), [합성 보정본](../apps/library-web/src/fixture-corrected-browser.test.mjs)입니다.

원본의 화면 주소 21개와 같은 경로는 모두 있지만, 주소가 있다는 것만으로 화면의 모든 내용과 동작을 옮겼다는 뜻은 아닙니다. 아래에 확인한 범위와 남은 차이를 적었습니다.

| 화면 | 원본에서 확인한 구성·동작 | 공개판의 상태와 남은 차이 |
| --- | --- | --- |
| `/` | 로그인 후 자료 목록·검색과 문서 열기. | 합성 자료·검색·로그인 제공. 실제 문서 서버와 권한은 미연결. |
| `/bookmarks`, `/mypage` | 저장한 게시물 또는 내 활동 목록과 조회 오류 안내. | 합성 보관함·활동 목록·빈 상태와 합성 조회 오류 제공 ([#322](https://github.com/BreakSilence-Basoon/vintad3e/pull/322)). 실제 활동·조회 서버는 미연결. |
| `/members` | 구성원 검색·목록과 빈 결과, 조회 오류 안내. | 합성 구성원 검색·빈 결과·중복 검색어와 합성 조회 오류를 PC·모바일에서 검사. 실제 직원·서버는 미연결. |
| `/meetings` | 회의 목록·생성과 조회 오류 안내. | 합성 회의 생성·목록·합성 조회 오류 제공 ([#321](https://github.com/BreakSilence-Basoon/vintad3e/pull/321)). 실제 회의 서버는 미연결. |
| `/meetings/[meetingId]` | 녹화·녹음 첨부와 전사본·보정본·요약 등록, 작성 방식 세 가지 및 근거 문서 선택. | 지정 합성 파일의 첨부·등록과 합성 확인 제공. 세 단계와 작성 방식 조합 및 입력 길이·상위 문서 검증을 검사. 실제 파일·회의와 권한 서버는 미연결. |
| `/objects`, `/objects/new` | 파일 목록·빈 상태·오류와 파일 올리기 확인 절차. | 합성 목록·빈 상태·합성 조회 오류와 지정 합성 파일의 업로드 확인 제공 ([#320](https://github.com/BreakSilence-Basoon/vintad3e/pull/320)). 실제 파일 서버는 미연결. |
| `/objects/[objectId]` | 파일 열기와 연결된 문서·보정본 확인. | 지정 합성 파일과 서식 있는 보정본을 열고 화자·교정 근거·본문 복귀를 PC·모바일에서 검사. 실제 파일과 임의 형식의 보정본은 미연결 또는 미대조. |
| `/public/objects/[objectId]`, `/public/documents/[documentId]` | 공개 주소에서 파일 또는 문서를 열기. | 지정 합성 자료 열기 제공. 실제 공개 자료 서버는 미연결. |
| `/ir/[id]`, `/native/[id]` | 내부 문서 제목·본문·목차와 문서 정보 조회. | 합성 문서와 로그인 경로 제공. 실제 내부 자료·권한은 미연결. |
| `/publications/[id]` | 발행 문서 읽기·정보·다운로드·공유·댓글과 글자 수 표시, 권한별 보관. | 합성 문서·도구·댓글 및 목록 제외 제공. 원본의 댓글 글자 수 표시를 복원. 실제 문서와 권한은 미연결. |

| `/documents/[slug]` | 로그인 확인 뒤 찾을 수 없는 문서로 처리하는 이전 주소. | 합성 로그인 확인 뒤 없는 문서로 처리. 실제 인증은 미연결. |
| `/sign-in` | 로그인·로그인 화면 보기·복귀와 인증 실패 안내. | 합성 로그인·화면 보기·복귀와 원본 오류 안내 제공. 오류 유형·주소 정리·중복 화면 보기 값을 PC·모바일에서 검사. 실제 인증 제공자는 미연결. |
| `/auth/session-resume` | 안전한 주소를 보존해 세션 갱신 뒤 재인증으로 이동. | 합성 세션과 로그인 복귀 제공. 실제 갱신은 미연결. |
| `/confirmations/[proposalId]` | 서버 제안·권한 확인, 검토·승인, 만료·오류·재인증 안내. | 합성 세션별 확인·발행, 재로그인, 서버 및 저장 읽기·쓰기 실패와 재시도, 새로고침 후 발행 결과 복구를 PC·모바일에서 검사. 보관·손상된 상태는 보존하며 다시 발행하지 않음. 실제 제안·권한·재인증과 실제 서버 오류는 미연결. |

확인 주소에서는 고정된 발행 제안, 지정된 합성 파일의 업로드 제안과 일부 합성 내부 문서·Notion 이관 제안을 복구합니다. 원본의 나머지 내부 문서 동작은 미이관입니다.

| 확인 주소에서 복구하는 제안 | 원본의 주요 동작 | 공개판 상태 |
| --- | --- | --- |
| 문서 발행 | 최신 상태 조회 → 제안 검토 → 변경 확인 → 문서 발행 | 합성 세션에서 제공. |
| 파일 업로드 | 최신 상태 조회 → 제안 검토 → 변경 확인 | 지정된 합성 파일 제안은 같은 합성 세션에서 복구 가능. 실제 파일과 권한은 미연결. |
| 내부 문서 이관 | 개별 제안의 검토·변경 확인·적용 또는 묶음 이관 확인·적용 | 정해진 합성 단건·묶음 이관, 첨부 예약·연결, 문서 삭제·복구 및 격리된 첨부 정리 제안을 시험 경로에서 만들고 확인 주소로 복구. 실제 문서 이관과 나머지 생명주기 제안은 미연결 또는 미이관. |
| Notion 문서 발행 | 최신 상태 조회 → 제안 검토 → 변경 확인 → 문서 발행 | 정해진 합성 발행·삭제·복구 제안을 시험 경로에서 만들고 확인 주소로 복구. 발행 뒤 해당 합성 세션에서 합성 문서를 열 수 있음. 실제 Notion 자료·인증·서버는 미연결. |

지정된 합성 파일과 내부 문서·Notion 제안은 같은 합성 세션에서 확인 주소를 다시 열어 검토할 수 있습니다. 같은 브라우저 탭에서 재로그인하면 탭에 보관한 복구 정보로 이어가며, 그 정보가 없는 다른 세션에서는 볼 수 없습니다. 제안 만료나 합성 서버 재시작 뒤에는 복구되지 않습니다. 내부 문서·Notion 예시는 시험 경로로만 만들 수 있고 앱에 새 제안 버튼은 없습니다. 실제 파일·문서, 작업 권한과 인증은 연결하지 않았습니다.

첨부 정리는 문서 삭제 근거와 다른 문서·회의의 공유 참조를 모두 확인해야 합니다. 정리 예시는 다른 문서나 회의에서 참조할 수 없는 별도 합성 파일에만 적용합니다. 회의에서도 사용될 수 있는 일반 합성 파일은 정리하지 않습니다. 정리는 파일의 합성 내용을 지우지 않고 해당 레코드를 숨깁니다.

위 표에 없는 모든 입력 조합과 실제 서버·권한의 오류는 별도 대조가 필요합니다. 합성 서버의 확인은 실제 업무 권한을 부여하지 않습니다.
