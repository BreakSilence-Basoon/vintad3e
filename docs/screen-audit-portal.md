# Portal 화면별 대조

원본 화면 코드와 공개판 코드를 비교한 기록입니다. 공개판의 계정·자료·권한은 합성 환경이며 실제 로그인이나 회사 서버를 확인한 결과가 아닙니다. 경로별 합성 브라우저 검사 근거는 [Portal 검사](../apps/portal-web/test/fixture-browser.test.mjs)입니다.

| 화면 | 원본에서 확인한 화면과 동작 | 공개판의 상태와 남은 차이 |
| --- | --- | --- |
| `/` | 업무 앱·외부 링크·관리 바로가기 세 화면 전환, 앱 이동, 로그아웃. 앱이 없으면 빈 목록, 목록 조회가 실패하면 오류를 표시. | 전환·합성 앱 이동·합성 로그아웃과 빈 목록·조회 오류 제공 ([#305](https://github.com/BreakSilence-Basoon/vintad3e/pull/305)). 회사 링크와 이미지, 실제 권한·서버 응답은 사용하지 않음. |
| `/about` | 공개 소개 제목과 문단을 순서대로 표시. 본문에 입력·전송 단추 없음. | 같은 구성에 공개 가능한 합성 소개를 표시. 회사 소개 원문은 싣지 않음. |
| `/sign-in` | 회사 계정 로그인, 로그인 화면 보기와 복귀, 인증·접근 상태에 따른 안내. | 합성 로그인과 로그인 화면 보기·복귀 제공. 실제 인증 제공자 오류와 실제 접근 거부 분기는 미연결. |
| `/auth/session-resume` | 안전한 돌아갈 주소를 유지하고 세션 갱신을 마친 뒤 재인증 경로로 이동. 중간 화면은 빈 표시자. | 합성 세션 여부에 따라 안전한 주소 또는 합성 로그인으로 이동. 실제 세션 갱신·재인증 경로는 미연결. |
| `/confirmations/[proposalId]` | 서버 제안 불러오기·검토·확인, 제안과 권한 상태·만료·오류 및 재인증 안내. | 정해진 합성 제안의 불러오기·검토·확인과 오류 복구 제공. 실제 제안·권한·재인증·업무 실행과 그 오류 상태는 미연결 또는 미대조. |

빈 상태·오류를 포함한 실제 회사 서버의 응답과 권한별 모든 분기는 공개판에서 검증하지 않았습니다. 위 표는 합성 환경에서 연결된 범위와 확인하지 못한 부분을 구분합니다.
