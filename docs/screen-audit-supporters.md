# Supporters 화면별 대조

원본 화면과 공개판 코드를 비교한 기록입니다. 공개판은 합성 계정·자료를 사용합니다. 실제 정산 공식·금액·직원 정보는 옮기지 않으며 실제 인증과 외부 서비스는 검증하지 않았습니다. 검사 근거는 [쿠폰·정산](../apps/supporters-web/src/coupon-fixture-browser.test.mjs), [본인 SNS](../apps/supporters-web/src/sns-fixture-self-browser.test.mjs), [키보드 동작](../apps/supporters-web/src/interaction-keyboard-browser.test.mjs)입니다.

| 화면 | 원본에서 확인한 구성·동작 | 공개판의 상태와 남은 차이 |
| --- | --- | --- |
| `/` | 구성원·기간을 선택해 조회하고 세션 복귀 뒤 선택을 복원. | 합성 구성원·기간 조회와 로그인 복귀 제공. 실제 권한·조회 서버는 미연결. |
| `/coupon` | 구성원 선택, 쿠폰 코드·링크 복사와 사용 정보, 주문 조회 오류 안내. | 합성 쿠폰·복사와 주문 조회 오류·일부 누락 안내 제공 ([#308](https://github.com/BreakSilence-Basoon/vintad3e/pull/308), [#317](https://github.com/BreakSilence-Basoon/vintad3e/pull/317)). 실제 발급·주문 서버와 권한은 미연결. |
| `/formula-info` | 정산 안내, 언어 전환·목차·복사. | 탐색 구성과 합성 안내 제공. 실제 협업 조건과 계산 내용은 제외. |
| `/formula` | 관리자용 정산 계산 구조·기준 표·용어 설명. | 설정에 넣은 합성 예시와 용어 설명 제공. 실제 공식·금액·억제 로직은 제외. |
| `/instagram`, `/tiktok` | 구성원 선택과 연결 상태·성과 조회, 동기화·연결 해제, 조회 오류 안내. | 합성 성과 조회·정렬, 연결 해제 확인과 합성 연결 상태 오류 제공 ([#326](https://github.com/BreakSilence-Basoon/vintad3e/pull/326)). 실제 계정 연결·동기화·외부 서비스 오류는 미연결. |
| `/settlements` | 권한별 구성원 선택과 연도별 지급 상태 조회. | 합성 구성원과 지급 상태 제공. 저장된 합성 상태를 읽지 못하면 원본 오류 안내와 수정 비활성화를 표시하며, PC·모바일 검사에서 복구를 확인. 실제 정산·권한·서버 조회 오류는 미연결. |
| `/performance` | 접근을 확인한 뒤 홈으로 이동하는 이전 주소. | 합성 로그인 확인 뒤 홈으로 이동. 실제 접근 확인은 미연결. |
| `/sign-in` | 로그인, 로그인 화면 보기·복귀와 인증 실패 안내. | 합성 로그인·화면 보기·복귀 제공. 실제 인증 실패 안내는 미연결. |
| `/auth/session-resume` | 안전한 주소를 유지하고 세션 갱신 뒤 재인증 경로로 복귀. | 합성 세션과 안전한 주소·로그인 복귀 제공. 실제 세션 갱신은 미연결. |
| `/confirmations/[proposalId]` | 서버 제안과 권한 확인, 검토·승인, 만료·오류·재인증 안내. | 정해진 합성 제안의 확인 제공. 실제 서버 제안·권한·재인증과 모든 오류 분기는 미연결 또는 미대조. |

개인정보처리방침과 이용약관은 가게마다 직접 준비해야 하므로 원본 회사의 내용을 옮기지 않습니다. 위 표는 합성 기능과 실제 연결이 필요한 부분을 구분하며, 미대조 분기까지 일치한다고 뜻하지 않습니다.
