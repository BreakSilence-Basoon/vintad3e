# Timetable 화면별 대조

원본 화면과 공개판의 합성 흐름을 비교했습니다. 실제 출퇴근 기록·계정 권한·등록 기기는 연결하지 않았습니다. 검사 근거는 [일정](../apps/timetable-web/src/fixture-schedule-admin-browser.test.mjs), [출근부](../apps/timetable-web/src/fixture-history-admin-browser.test.mjs), [본인 화면](../apps/timetable-web/src/fixture-self-browser.test.mjs), [키보드 동작](../apps/timetable-web/src/interaction-keyboard-browser.test.mjs)입니다.

| 화면 | 원본에서 확인한 구성·동작 | 공개판의 상태와 남은 차이 |
| --- | --- | --- |
| `/` | 출근부·시간표 전환, 선택 화면 조회, 등록된 기기의 진입 분기. | 합성 화면 전환과 기기 분기 제공. 선택 화면만 불러오는 처리는 #301에서 반영. 실제 기록과 권한은 미연결. |
| `/history`, `/schedule` | 출근부 조건·페이지 또는 시간표 월을 보존해 홈의 해당 화면으로 이동. | 합성 홈에 조건과 월을 전달. 실제 데이터 조회는 미연결. |
| `/admin/attendance` | 관리자 출퇴근 기록 조회·조정과 저장. | 합성 기록·수정·저장 제공. 실제 근태와 관리자 권한은 미연결. |
| `/admin/schedule` | 선택한 달의 관리자 시간표 이동·조회. | 합성 시간표와 달 이동 제공. 실제 근무 일정은 미연결. |
| `/admin/kiosks` | 기기 목록·선택·등록·해제, QR 발급 화면과 입력·오류 안내. | 합성 기기 등록·해제·QR과 빈 입력·합성 서버 오류 제공. 실제 기기와 권한은 미연결. |
| `/kiosk`, `/kiosk/setup` | 등록된 기기의 QR 화면, 미등록 기기 안내와 설정 이동. | 합성 기기 등록 여부에 따른 화면과 이동 제공. 실제 기기 등록은 미연결. |
| `/scan` | 로그인 후 카메라로 QR을 읽고 카메라 오류·재시도를 안내. | 합성 로그인과 카메라 거부·재시도 안내 제공. PC·모바일 폭에서 합성 영상의 QR로 출근·퇴근 기록을 검사. 실제 카메라와 출퇴근 서버는 미연결. |
| `/clock-code` | QR 스캔 화면으로 이동하는 이전 주소. | 같은 스캔 주소로 이동. |
| `/access-denied` | 접근 거부 사유와 다른 계정 로그인 안내. | 합성 사유 안내와 로그아웃 제공. 실제 계정 전환·권한 판정은 미연결. |
| `/sign-in` | 로그인·로그인 화면 보기·복귀와 인증 실패 안내. | 합성 로그인·화면 보기·복귀 제공. 실제 인증 오류는 미연결. |
| `/auth/session-resume` | 안전한 주소를 보존하고 세션 갱신 뒤 재인증으로 이동. | 합성 로그인 또는 돌아갈 주소로 이동. 실제 갱신은 미연결. |
| `/confirmations/[proposalId]` | 서버 제안·권한 확인, 검토·승인, 만료·오류·재인증 안내. | 고정된 합성 제안의 확인 제공. 실제 제안·권한·재인증 및 모든 오류 분기는 미연결 또는 미대조. |

개인정보처리방침과 이용약관은 각 가게가 직접 준비합니다. 위 표에 기록하지 않은 입력 조합과 실제 서버의 모든 오류는 별도 대조가 필요합니다.
