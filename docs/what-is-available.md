# 빈타제 공개판에서 지금 할 수 있는 일

빈타제는 작은 가게에 필요한 일하는 도구를 만들어 가는 공개 소스 프로젝트입니다. **지금은 내 컴퓨터에서 화면과 합성 자료로 흐름을 살펴볼 수 있는 단계입니다.** 실제 직원·고객·매출·정산 정보를 넣어 영업에 사용하는 제품은 아직 아닙니다.

## 지금 살펴볼 수 있는 것

각 앱을 실행하고 가상의 자료를 켜면 다음과 같은 흐름을 확인할 수 있습니다. 자료는 가게의 실제 정보가 아닙니다.

| 도구 | 살펴볼 수 있는 일 |
| --- | --- |
| 포털 | 앱으로 이동하고 합성 로그인과 변경 확인 흐름을 살펴봅니다. |
| Timetable | 출근부와 일정을 보고, 합성 출퇴근 QR과 기기 관리 흐름을 확인합니다. |
| Apparel | 합성 상품·재고·판매를 찾아보고 재고 수량을 바꾸거나 합성 갱신을 시험합니다. |
| Supporters | 합성 쿠폰과 게시물, 정산 화면과 설정형 계산식을 살펴봅니다. |
| Partners | 합성 협업 일정·정산, 협업처별 게스트 화면과 작가·DJ 안내를 확인합니다. |
| Library | 합성 문서를 검색·보관·댓글 작성하고, 합성 회의와 정해진 합성 파일 업로드를 시험합니다. |
| Floor | 합성 판매 기록과 영업일 요약, 재료 현황을 살펴봅니다. |
| Creative | 합성 프로젝트 목록과 변경 확인 흐름을 살펴봅니다. |
| Admin | 합성 구성원·앱 권한 표·변경 기록을 살펴봅니다. |

[처음 실행하기](first-run.md)에서 내 컴퓨터에 여는 순서와 앱별 안내를 볼 수 있습니다. 일부 변경은 현재 브라우저 탭이나 실행 중인 서버 메모리에만 남아 탭을 닫거나 서버를 다시 켜면 사라집니다. 각 앱이 무엇을 보관하는지는 해당 앱의 안내를 확인하세요.

## 아직 할 수 없는 것

- 가게의 실제 직원·고객 정보를 안전하게 넣고 직원별 접근 권한을 관리하는 일
- 실제 판매·출퇴근·재고·정산을 기록하고 백업·복구하는 업무용 운영
- 실제 SNS나 POS를 연결해 데이터를 가져오고, 실제 파일을 자유롭게 올려 보관하는 일
- 가게별 사업 조건에 맞춘 정산 공식·법적 문서와 외부 서비스 계약을 자동으로 완성하는 일

일부 앱에 합성 로그인이나 기록 화면이 있지만 실제 신원 확인·권한 부여·결제·지급과 연결되지 않습니다. 공개 API 실험도 업무용 설치나 운영 준비가 끝났다는 뜻은 아닙니다. 실제 데이터를 연결하려면 저장소·권한·백업을 새로 만들고 검증해야 합니다. 앞으로의 선택지는 [가게 데이터 연결 방식 비교](store-data-options.md)에 정리했습니다.

| 도구 | 아직 연결되지 않은 실제 업무 |
| --- | --- |
| 포털 | 실제 계정·앱 접근 권한·업무 서버 상태와 로그아웃 |
| Timetable | 실제 직원의 출퇴근·일정·기기 및 관리자 권한 |
| Apparel | 실제 상품·재고·판매·POS와 직원 권한, 안전한 서버 저장 |
| Supporters | 실제 쿠폰 주문·SNS 계정·정산·지급과 직원 권한 |
| Partners | 실제 협업처·게스트 계정·판매·재고·정산과 접근 권한 |
| Library | 실제 문서·파일·회의 저장과 직원 권한, 실제 내부 문서 이관, 만료된 Notion 삭제·복구 제안 다시 받기 |
| Floor | 실제 판매·결제·재고·구매 및 직원 권한 |
| Creative | 실제 프로젝트·업무 변경과 직원 권한 |
| Admin | 실제 구성원·앱 접근 권한과 변경 이력 |

Library의 파일 올리기는 정해진 합성 파일만 시험할 수 있습니다. 합성 확인 화면은 실제 서버의 승인 보호가 아니며 임의의 가게 파일을 저장하지 않습니다. 파일 올리기·내부 문서 이관·Notion 제안의 자세한 차이는 [화면·기능 대조](screen-audit-followup.md#library에서-아직-제공하지-않는-기능)를 확인하세요.

가게마다 필요한 개인정보처리방침이나 이용약관은 자기 운영 방식에 맞게 직접 준비해야 합니다. 설치와 맞춤 지원은 [mow.codes](https://mow.codes)에 문의할 수 있습니다. 소스 사용 조건은 [Elastic License 2.0](../LICENSE)을 확인하세요.
