# 빈타제 공개판에서 할 수 있는 일

빈타제는 작은 가게를 위한 업무 도구를 만들어 가는 공개 소스입니다. **지금은 가상의 자료로 화면과 사용 순서를 살펴볼 수 있습니다.** 실제 직원·고객·매출·정산 정보를 넣어 영업에 쓰는 제품은 아직 아닙니다.

## 지금 바로 써 볼 수 있는 것

내 컴퓨터에서 앱을 실행하면 가상의 사람·상품·금액으로 다음 화면을 눌러 볼 수 있습니다. 이 설명서와 앱 안내서에서 말하는 ‘합성 자료’는 이러한 연습용 자료입니다. 로그인 버튼도 연습용이어서 실제 계정을 확인하지 않습니다.

| 도구 | 연습용 자료로 해 볼 수 있는 일 |
| --- | --- |
| 포털 | 다른 앱으로 이동하고 로그인과 변경 확인 화면을 살펴봅니다. |
| Timetable | 출근부와 일정을 보고 출퇴근 QR과 기기 관리를 살펴봅니다. |
| Apparel | 상품·재고·판매를 찾아보고 재고 수량을 바꿔 봅니다. |
| Supporters | 쿠폰·게시물·정산 화면과 예시 계산 방식을 살펴봅니다. |
| Partners | 협업 일정·정산, 협업처별 읽기 화면과 작가·DJ 안내를 살펴봅니다. |
| Library | 문서 검색·보관·댓글 작성, 회의와 정해진 예시 파일 올리기를 해 봅니다. |
| Floor | 판매 기록·영업일 요약과 재료 현황을 살펴봅니다. |
| Creative | 프로젝트 목록과 변경 확인 화면을 살펴봅니다. |
| Admin | 구성원 목록·앱 접근 표·변경 기록을 살펴봅니다. |

[처음 실행하기](first-run.md)를 따라 하면 각 앱을 여는 방법을 볼 수 있습니다. 일부 변경은 현재 브라우저 탭이나 실행 중인 프로그램에만 남아 탭을 닫거나 프로그램을 다시 켜면 사라집니다. 앱마다 남는 범위는 각 앱 안내서를 확인하세요.

## 우리 가게 자료로 쓰려면 준비할 것

**아래 준비를 했더라도 지금 공개판에 설정만 바꿔 실제 자료를 넣을 수는 없습니다.** 안전하게 쓰려면 필요한 기능을 만들고 검증하는 작업이 더 필요합니다.

1. **자료를 보관할 곳**: 상품·직원·고객 정보를 어디에 저장하고 누가 관리할지 정합니다. 문제가 생겼을 때를 대비해 사본을 남기고 복구할 방법도 준비합니다.
2. **로그인과 접근 범위**: 직원마다 무엇을 보고 바꿀 수 있는지, 퇴사하면 접근을 어떻게 끊을지 정합니다. 연습용 로그인은 실제 신원이나 권한을 확인하지 않습니다.
3. **가게의 업무에 맞는 연결**: 판매 기록, 계산대, SNS, 파일과 정산 중 무엇을 연결할지 정하고 각 서비스의 가입·비용·사용 조건을 확인합니다.
4. **가게에 맞는 법적 문서와 시험**: 개인정보처리방침과 이용약관이 필요하면 가게의 운영 방식에 맞게 직접 준비합니다. 실제 정보를 넣기 전에 가상 자료로 저장·접근·복구가 의도대로 되는지 확인합니다.

가능한 연결 방식과 준비할 일을 [가게 자료 연결 방법 비교](store-data-options.md)에서 볼 수 있습니다. 설치나 맞춤 지원은 [mow.codes](https://mow.codes)에 문의할 수 있습니다.

## 아직 제공하지 않는 것

실제 정보를 안전하게 저장하고 여러 직원이 함께 사용하는 기능, 실제 판매·출퇴근·재고·정산 기록의 보관과 복구, SNS·계산대 연결은 아직 제공하지 않습니다. 실제 결제나 지급도 이 화면에서 이뤄지지 않습니다.

| 도구 | 아직 연결되지 않은 실제 업무 |
| --- | --- |
| 포털 | 실제 계정·앱 접근 권한과 업무 서비스 상태·로그아웃 |
| Timetable | 실제 직원의 출퇴근·일정·기기 및 관리자 권한 |
| Apparel | 실제 상품·재고·판매·계산대와 직원 권한, 안전한 자료 저장 |
| Supporters | 실제 쿠폰 주문·SNS 계정·정산·지급과 직원 권한 |
| Partners | 실제 협업처·게스트 계정·판매·재고·정산과 접근 권한 |
| Library | 실제 문서·파일·회의 저장과 직원 권한, 내부 문서 옮기기, Notion에서 가져온 문서의 삭제·복구 요청이 만료됐을 때 다시 받기 |
| Floor | 실제 판매·결제·재고·구매 및 직원 권한 |
| Creative | 실제 프로젝트·업무 변경과 직원 권한 |
| Admin | 실제 구성원·앱 접근 권한과 변경 이력 |

Library의 파일 올리기는 정해진 연습용 파일만 시험할 수 있습니다. 이 확인 화면은 실제 업무를 승인하거나 안전하게 보호하지 않으며 임의의 가게 파일을 저장하지 않습니다. 더 자세한 차이는 [화면·기능 대조](screen-audit-followup.md#library에서-아직-제공하지-않는-기능)를 확인하세요.
